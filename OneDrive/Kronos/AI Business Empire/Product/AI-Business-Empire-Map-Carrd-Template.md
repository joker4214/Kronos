## CARRD BUILD INSTRUCTIONS

### Step 1: Create a new Carrd site
1. Go to **carrd.co**
2. Click **"Start building"** (or **"New site"** if logged in)
3. Choose **"One Page"** as the template
4. Pick a domain or use a Carrd subdomain

### Step 2: Remove default sections
Delete all default sections — build minimal, start fresh.

### Step 3: Add a Hero Section
1. **"+ Add Section"** → **Hero** (or **Minimal Hero**)
2. Fill in:
   - **Heading:** `You built an AI thing. Now what?`
   - **Subheading:** `Answer 5 questions. Find out exactly what you should build, market, and sell — free.`
   - **Background:** solid dark color (charcoal/navy) or subtle gradient
   - **Text color:** white
   - Leave the CTA button empty here — add it separately in Step 5

### Step 4: Add Body Copy Section
1. **"+ Add Section"** → **Text**
2. Paste the Body Copy above
3. Formatting: left-aligned, 16–18px, line height 1.6, max width ~600px (Carrd handles this)

### Step 5: Add Benefits Section
1. **"+ Add Section"** → **Features** (or **Text** for more control)
2. Add the 3 benefit bullets above, 1–3 columns depending on how it looks on mobile
3. Icons optional (simple checkmarks work fine)

### Step 6: Add CTA Button Section
1. **"+ Add Section"** → **Button** (or **Action**)
2. Fill in:
   - **Button text:** `Take the 2-Minute Quiz →`
   - **Button URL:** `https://www.dharmasestheticdesign.com/quiz.html`
   - **Style:** prominent — larger, contrasting color (bright teal/orange/lime against the dark hero)
   - **Open in new tab:** Yes
3. Add a **Text** section right below with: `Free. No signup to start — just to see your result.` (smaller, lighter gray, 14px)

### Step 7: Add Footer
1. **"+ Add Section"** → **Text**
2. Add: `© 2026 Jason Gregory. Built for people figuring out their AI business.`
3. Style: centered, 12–14px, light gray

### Step 8: Mobile Optimization
1. Use Carrd's mobile preview (phone icon in the editor)
2. Check: text stays ≥14px, button is full-width/easy to tap, spacing isn't cramped
3. Adjust section padding/margins if needed

### Step 9: Colors & Fonts (optional polish)
- **Background:** white or very light gray (below the dark hero)
- **Text:** dark gray/black
- **Accent (button):** one bold color — teal `#00BFA5`, orange `#FF6B35`, or lime `#00E676`
- **Fonts:** 2 max — Carrd's defaults (Inter, Helvetica) are fine

### Step 10: Publish
1. Click **Publish** (top right)
2. Set the domain
3. Publish, then **click the quiz link from the live site** to confirm it actually opens `quiz.html`
